# ข้อจำกัดที่พบขณะต่อสคริปต์

- ระบบ: Telesale UAT / ฟอร์มผู้เอาประกันของใบคำขอที่คัดลอกจาก PH Application 8100002
- สิ่งที่อ่านจาก DOM ของฟอร์มจริง: ช่องชื่อและนามสกุลมี native HTML `pattern="[A-Z0-9]*"`
- ข้อมูลจาก Application เป็นชื่อภาษาไทย จึงมี `validity.valid=false` และข้อความ `Please match the requested format.`
- Email จากต้นทางเป็น `-` ซึ่งไม่ผ่านชนิด email; สคริปต์ล้างเป็นค่าว่างตามต้นฉบับ
- เมื่อใช้ชื่อภาษาไทยเดิมและกดบันทึก ไม่มีคำขอบันทึกจากฟอร์มและไม่มี Success จึงไม่ใช่หลักฐานว่าการบันทึกสำเร็จ
- ทางเลือกของข้อมูล UAT: กำหนด `insuredNameOverride` ใน scenario ให้ใช้ชื่อจำลองที่ผ่าน pattern ปัจจุบัน หรือคงข้อมูลต้นทางและรายงาน blocked
- สคริปต์ไม่ลบ pattern ไม่ปิด native validation และไม่แก้ DOM/เรียก backend แทน UI
- ผลของการใช้ชื่อจำลองไม่ครอบคลุมการบันทึกชื่อภาษาไทย ควรให้ทีมพัฒนาตรวจ pattern กับเกณฑ์ชื่อบุคคลที่ระบบต้องรองรับ
